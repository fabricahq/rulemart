  • Use Inter Semibold for the wordmark. The supplied outlined logos preserve its spacing.
  • Keep at least two stroke widths of clear space around the symbol. The exported logos and app icons already include padding.
  • Use the dedicated favicon assets at 16 to 48px. Use the horizontal logo at 120px wide or larger.
  • Keep the symbol upright and proportional. Preserve all three layers and use one flat color.
  • Use the white logo on dark backgrounds and the dark logo on light backgrounds. Avoid gradients, shadows, and placing text inside the symbol.

Design source: Rulemart’s Inter typography and grayscale palette; Fabrica’s isometric geometry. Selected October 2, 2026.

Files and regeneration

logos/ contains transparent marks and outlined wordmarks. icons/ contains opaque app tiles. favicons/ contains browser and home-screen icons. source/ contains the editable symbol and licensed Inter font. SHA256SUMS records the package contents.

To regenerate exports, install the packages in requirements.txt in a Python environment and install rsvg-convert, then run python brand/build.py from the repository root. This rebuilds the package, not the site. The site intentionally uses a heavier stroke in its header and favicon for small sizes.
