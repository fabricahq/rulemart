## ✨ New Features

### Streamlined dashboard

"Your dashboard" at `/me` now has four tabs, each showing only its own content:

- **My libraries** lists the libraries you and your organizations publish
- **Projects** lists your repositories that use Code Rules and how many rule updates each is waiting for
- **Starred rules** lists your stars
- **Account** shows your account's facts, Sign out, and Delete your account.

(#48)

### Only a repository's maintainers can add it

Adding a library to Rulemart now needs write access to its repository on GitHub. When you confirm a repository's address, and again when the listing is created, Rulemart checks with GitHub that your account may push to it, so the people who can fix or remove a listing are the people who own the code. (#48)

### Deleting your account asks for your username

Delete your account now asks you to type your GitHub username exactly, in a dialog, before it deletes anything, and the server refuses any other value. Without scripts, the Account tab leads to a page that asks the same way. (#48)

### The GitHub App's webhook

When the operator routes it, the GitHub App "Rulemart by Fabrica" tells Rulemart as soon as someone installs, suspends, or uninstalls it, and Rulemart stops reading private repositories through that installation at once rather than at the next refresh. Rulemart treats each delivery as a prompt to ask GitHub for the installation's current state, acts on a delivery once however many times it arrives, and answers nothing but the webhook through the webhook's own address. The privacy page says what a delivery discards once the webhook is routed. The webhook stays off until the infrastructure routes it, as described under Deploying below. (#41)

### The worker can read GitHub as the Rulemart app

The worker, which checks listings and watches libraries for new releases, can now authenticate to GitHub as the GitHub App, minting a short-lived installation token every hour from the app's private key, instead of with an ephemeral personal access token. (#44)

## ⬆️ Improvements

- The Rulemart site now lists the version it's published in the footer. (#48)
- The FAQ's answer to "What is Rulemart?" now leads to the about page. (#50)
- The test library `fabricahq/code-rules-test-library` is no longer vetted, so it leaves the vetted lists, groups, and search, and shows only under unvetted libraries. (#47)
