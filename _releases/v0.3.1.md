## 🐛 Squashed Bugs

### Add a library offers the libraries you can write to again

After v0.3.0, the Add a library page could dim a library you maintain as "Only someone with write access can add it". It was showing a list of your libraries that Rulemart read from GitHub before it recorded write access. Rulemart now reads GitHub again instead of showing that outdated list, even after a read fails. Each signed-in account reads GitHub once more after this release deploys. (#56)

### Checkout says why it has no projects to offer

- When reading your projects from GitHub failed, is still under way, or needs you to sign in again, checkout now says which, instead of saying it found no projects, and lets you enter a repository. (#56)
- Checking out for a repository you enter while that read is under way now works, instead of failing. (#56)

### Smaller fixes

- The header's sign-in button reads "Sign in with GitHub" again, instead of "Sign inwith GitHub". (#57)
