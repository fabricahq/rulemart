## ✨ New Features

### Libraries in the Trail Guide layout show up again

Rulemart now reads library releases published from `.trailguide/`, as well as releases at the repository's root or in `.code-rules/`. Before, a release in the new layout failed to ingest, so a library that moved, such as Fabrica's public library at `release/3`, stopped updating. A library keeps its history when it moves, and rule pages link each file where its release keeps it on GitHub. (#62)

This release adds a migration that adds a column to a table the previous release reads. The column has a default, so the previous release keeps working while it serves the site.

## ⬆️ Improvements

### Rulemart speaks Trail Guide

Code Rules is now Trail Guide, and Rulemart's pages, help, and links say so. Rulemart finds your projects in `.trailguide/`, and still finds projects that keep their files in `.code-rules/`. (#59)

### Checkout writes Trail Guide 0.4.0 commands

Checkout now gives you `trailguide project add source` commands that select whole groups and individual rules, and asks for Trail Guide 0.4.0 or later. For a project that already uses the library, it says what to add to the source's `rules.include`, and to rewrite a version 1 configuration first. (#61)
