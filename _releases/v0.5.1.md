## 🐛 Squashed Bugs

### Libraries in library schema version 2 ingest again

Fabrica's public library moved to trailguide's library schema version 2 in `release/8`, and Rulemart read only version 1. So the worker's hourly job for the library failed, retried, and set off the jobs queue's alarm. Rulemart now reads library schema version 2, so those releases ingest. A library whose latest release is still on version 1 now tells its lister to move to version 2, and the catalog keeps the releases it already has. (#70)

This release adds no migrations.
